# 💅 Mi Gomes — Nail Designer

Landing page desenvolvida para uma esmalteria, com uma proposta visual **elegante, sofisticada e moderna**, criada para apresentar os serviços, trabalhos e diferenciais da profissional de forma atrativa e facilitar o contato para agendamento.

## ✨ Sobre o projeto

O projeto foi desenvolvido com foco em **experiência do usuário (UX)** e **design responsivo**, utilizando uma identidade visual baseada em tons escuros e detalhes dourados para transmitir uma sensação de luxo, beleza e sofisticação.

A landing page apresenta os principais serviços da esmalteria, galeria de trabalhos, informações sobre a profissional e uma chamada para agendamento através do WhatsApp.

## 🎯 Objetivos

* Criar uma presença digital profissional para a esmalteria
* Apresentar os serviços de forma visual e organizada
* Destacar os trabalhos realizados através de uma galeria
* Facilitar o contato com a profissional
* Direcionar clientes para o agendamento via WhatsApp
* Proporcionar uma experiência agradável em dispositivos móveis e desktop

## 🚀 Funcionalidades

* 🖼️ **Hero Section** com destaque visual
* 💅 **Galeria de trabalhos** em carousel
* ✨ Apresentação dos serviços
* 📱 Layout totalmente responsivo
* 📲 Botão de agendamento via WhatsApp
* 🎨 Identidade visual personalizada
* ⚡ Animações e transições para melhorar a experiência
* 🧭 Navegação entre as seções da landing page
* 📸 Otimização das imagens utilizando `next/image`

## 🛠️ Tecnologias utilizadas

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**

## ⚙️ Como executar o projeto

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta:

```bash
cd naildesigner
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```
